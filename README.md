# Face Mask Adherence Analysis

## Project Overview
This project investigates behavioural, psychological, and demographic predictors of face mask adherence in Australia during the COVID-19 pandemic using machine learning techniques.

## Objectives
- Explore behavioural patterns associated with face mask adherence
- Compare machine learning classification models
- Identify the strongest predictors of protective health behaviour

## Methods
The project uses:
- Exploratory Data Analysis (EDA)
- Logistic Regression
- Random Forest
- XGBoost
- 5-Fold Cross Validation
- Hyperparameter Tuning
- ROC and AUC Evaluation

## Dataset
Australian COVID-19 behavioural survey dataset containing demographic, psychological, and behavioural variables.

## Main Evaluation Metric
Area Under the ROC Curve (AUC)

## Repository Contents
- `face_mask_adherence_analysis.R` → Full modelling workflow
- `README.md` → Project documentation

## Key Findings
The tuned Random Forest and XGBoost models achieved strong predictive performance, with behavioural and psychological variables emerging as important predictors of face mask adherence.
